Common fixes

No numbers are showing up at all

Reload the page. The extension reads the results when the page loads, so if you installed it while a search was already open, that tab has not seen it yet. If a reload does not do it, open the extension's popup and check that the result types you care about are still ticked. They can be switched off individually.

My domain is not turning green

Paste the domain in however you like. https://www.example.com/pricing and example.com both work, and subdomains like shop.example.com match example.com too. What will not match is a typo or a different registered domain, so example.net stays grey when you searched for the .com.

A business shows up in the map results but stays grey

Map listings and Local Services Ads show a business name, not a web address, so there is no domain there to match against. Add the business name in the second column and it will start matching:

example.com | Example Company

The name is optional, but without it the local results have nothing to go on. Give both and you are covered everywhere.

The numbers went back to 1 on page two

That happens when the page was reached in a way that dropped Google's own offset from the address bar. Click through using the numbered pagination at the bottom of the results and it picks the count back up. The positions come from that offset, not from a count the extension keeps by itself, which is exactly why they stay honest.

Installing it

Install it from the Chrome Web Store, then pin the orange G icon to your toolbar. The full walkthrough, with pictures, is on the install guide, which also covers loading it unpacked from the source if you would rather run your own copy.

If Chrome warns that the extension is not trusted by Enhanced Safe Browsing, that refers to how long this publisher has been on the store rather than to the code. It went live in August 2026. Click Continue to install.

Reporting a bug

Bug reports are genuinely welcome, particularly about detection. Google changes the shape of its results pages regularly and something that worked in March can quietly stop working in August. The useful details are: the search term, which country you searched from, which page number, and what you expected to see instead.

If you have a GitHub account, raise it on the issue tracker, where you can also see what has already been reported. If you would rather not, use the contact details below and it will get logged for you.
