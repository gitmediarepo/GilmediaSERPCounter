SERP Counter Help

Numbers Google results by their true rank across pages and highlights the domains you care about.

What It Does

Google resets result numbering on every page. Page 3 shows 1-10, but those are really results 21-30. This extension fixes that by:

  • Numbering every result correctly across all pages: 1, 2, 3...21, 22, 23...etc
  • Highlighting your domains wherever they appear: organic results, Google Ads, the local pack, Local Services Ads, and Google Maps
  • Separating your results from mentions of your business name on other people's sites (LinkedIn, Indeed, ZoomInfo, etc)
  • Keeping a running log as you page through results for one search term
Perfect for

Spot checks on client rankings, competitive analysis, quick rank verification. Not a replacement for a dedicated rank tracker.

Domain List Format

Paste your list into the popup, one entry per line. Format:

example.com | Business Name another.com | Another Business domain-only.com Business Name Only

Rules

  • Domain alone matches organic results and Ads always, and matches the local pack, Local Services Ads, and Maps whenever Google's card exposes a website link for that listing. Subdomains match automatically.
  • Business name alone matches the local pack, Local Services Ads, and Maps, useful as a fallback when a listing doesn't show a website link.
  • Both gives the widest coverage: domain wherever a link is shown, name everywhere else.
  • Separators can be pipe |, comma ,, or tab. Paste straight from a spreadsheet.
  • Lines starting with # are comments and are ignored.
  • Extra spaces are trimmed. Column order doesn't matter.

How Results Are Marked

Green Your Domain

The domain matched. This result is yours. It's highlighted with a green outline.

Amber Mention of You

Only the business name matched, on somebody else's domain (LinkedIn, Indeed, etc). It's marked with an amber dashed outline.

Surfaces and Badges

  • Organic - Organic search result, numbered 1-100+ across all pages
  • Ad - Google Ads, numbered 1-2 or 1-3 per page
  • Map - Local pack and Google Maps, numbered 1-3 per page

Each surface counts on its own scale, so an ad block at the top never shifts your organic numbers.

The Summary Panel

A panel appears in the corner showing all your domains that showed up on the current page:

4 of 12 domains on page 1 example.com Business Name [3] [Ad 1] [Map 2] another.com Another Business [8]
  • Best position sorts to the top
  • Badges are colour-coded to match the result itself
  • The panel scrolls, so a busy page never runs off the bottom
  • Mention results appear in their own block, keyed by the site doing the mentioning

Running Log Across Pages

When you page from 1 to 2 to 3, the panel keeps a cumulative log instead of resetting. All your findings across all pages for one search term stay in view:

tracking "what you searched for" 3 of 12 domains across pages 1, 2, 3 example.com Business Name [3] [8·p2] [12·p3]

Organic ranks are absolute (they already say which page), so ads and map positions get the page appended when you're on multiple pages.

It resets automatically when you search for something else, and a Reset button clears it by hand.

Settings

Master Switch

The on/off switch at the top of the popup. When off, the extension leaves Google's page alone: no badges, no outlines, no panel, nothing logged. One click for screen shares.

Show / Hide Surfaces

  • Organic results - Toggle numbering and highlighting for organic
  • Google Ads - Toggle for paid ads
  • Local pack / Maps - Toggle for local results
  • Local Services Ads - Toggle for service ads
  • Mentions on other sites - Toggle name-only matches (amber badges)
  • Pagination at top of results - Repeat the page-number bar above the first result, so changing pages doesn't need a scroll to the bottom
  • Summary panel - Toggle the panel itself
  • Log detection to the console - Debug mode for developers

Remote List (sync across computers)

In the manager, paste a direct link to a shared .txt file (same format as the list) into the Remote list field. Sync now fetches it and replaces the list, backing up what it overwrote (an undo link appears). With Auto-refresh on, every computer signed into your Chrome profile re-pulls the file when its copy is over 12 hours old. GitHub raw and Dropbox links work; share-page links are converted automatically. The file's host must allow cross-site fetches (CORS).

If the file sits behind HTTP Basic Auth, click the lock icon next to Auto-refresh to reveal a username and password field. Credentials are sent as an Authorization header on the fetch, saved in your synced Chrome settings, and never appear in the URL itself. Each computer that points at the same URL still needs its own copy of the username and password entered once. The server must also answer the browser's CORS preflight (an OPTIONS request) for the Authorization header, not just the GET - a plain .htpasswd alone is not enough.

Domain List Manager

For lists bigger than a couple of dozen, open the manager by clicking Manage in the popup. It gives you:

  • Search by domain or business name
  • Inline editing of individual rows
  • Duplicates button to find repeated domains and filter to just those
  • Sort by file order, domain A-Z, or business name A-Z
  • Add / Remove single rows
  • Bulk edit toggle to edit the whole file as text
  • Import / Export your list as a .txt file
  • Drag and drop files onto the page to import

Everything saves as you type. Comment lines are preserved exactly where they are.

Import & Export

Import

Merge a .txt or .csv file without overwriting your current list. Three ways to import:

  • Click the Import icon button in the manager
  • Drag a .txt or .csv file onto the box
  • Paste text directly

Only new entries are added. Re-importing the same file twice is a no-op. Use Clear first if you want to replace the list outright.

Export

Download your list as a dated .txt file. The file can live in a shared drive or a repo.

Copy to Clipboard

A button in the panel header puts a one-line summary on your clipboard:

"what you searched" -> example.com: organic 3, ad 1, local 2

That drops straight into an email, report, or ticket.

Troubleshooting

Results aren't numbered, or numbering looks wrong

Google changes its markup without notice. If numbering breaks, try this to help diagnose:

  1. Tick Log detection to the console in the popup
  2. Reload the search page
  3. Right-click the page, click Inspect, then the Console tab
  4. Type __gilSerpDiag() and press Enter

It prints what every detection strategy matched plus sample markup. That's enough to fix a selector in five minutes instead of guesswork.

Local Services Ads aren't showing up

LSA detection keys off links to localservices.google.com. Some layouts render LSA without those links and will be missed.

Follow the console diagnostic above and send the output to the support page.

The extension shows "not trusted by Enhanced Safe Browsing"

That refers to how long this publisher has been on the store, not to the code. The extension went live in August 2026. Click Continue to install.

It requests one permission, storage, and no host permissions. It runs only on Google search and Maps pages. The only network request it can make is fetching your own shared list file, and only if you set a Remote list URL in the manager - leave that field empty and nothing leaves your browser.

Known Limits

  • This is not a rank tracker. Google personalises and localises results, so this reports what your browser sees from your location while signed into your account. Use it for spot checks and quick competitive looks, not trend reporting.
  • Continuous scroll appends results to the same page. Numbering follows along, but the count stays relative to whichever page you began on.
  • Results change without notice. If something stops working, Update your browser first. If it still breaks, use the diagnostic console mode above.
